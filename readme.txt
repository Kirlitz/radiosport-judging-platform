3. Требование к новым плагинам судейства
Теперь, чтобы добавить алгоритм для любого нового соревнования:

Создайте файл Python в папке app/judging/ (например, app/judging/khabarovsk_vhf.py).

Внутри файла определите понятное название и главную функцию run_judging(comp_id):

Как только вы сохраните файл khabarovsk_vhf.py, он автоматически появится в списке выбора при создании соревнования, а при нажатии кнопки «Судейство» администратор запустит его алгоритм.
